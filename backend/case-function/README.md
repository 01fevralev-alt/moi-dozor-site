# Автокейсы «Мой Дозор»

Сделка в amoCRM дошла до этапа **«Проверено»** → через 1–2 минуты в группу MAX приходит черновик кейса: текст и пронумерованные фото из «Папки Контент». Вы правите его ответами и нажимаете **«Опубликовать»** → через 1–2 минуты кейс на сайте: отдельная страница, а если есть фото — ещё и карточка в «Наших работах» на главной.

## Правки черновика — ответом на сообщение с черновиком
- `оставить 2, 4, 7` — публикуются только эти фото; `обложка 4` — главное фото; `убрать 3` / `вернуть 3` — по одному. Номер фото — в углу, когда откроете фото. Можно несколько строк в одном сообщении.
- `история: …` — 2–3 фразы: с чем пришёл клиент, что было особенного на объекте, что изменилось. Из них YandexGPT пишет «Задачу клиента» и «Что изменилось» на подробной странице. Можно надиктовать голосом → текстом.
- Из CRM без нейросети на страницу идут «Как проходил проект» (даты осмотра и монтажа, акт) и «Работы на объекте» («Расшифровка счета» без цен; всё ниже строки «Итого» отбрасывается). Частые вопросы подбираются по типу объекта.
- Скопировать текст черновика, исправить и отправить ответом — заменю поля, которые узнаю («Адрес:», «Заголовок:», «Кратко:», «Задача:», «Сделали:», «Камер:»…).
- Любое пожелание словами («короче», «добавь, что работали ночью») — YandexGPT перепишет.
- Кнопки: **Опубликовать**, **Отклонить**, **Собрать заново** (заново забрать фото из папки и переписать текст). Если фото нет — **Опубликовать без фото** или **Ждать фото** (14 дней раз в день проверяю папку).

⚠️ Перед публикацией проверьте фото: нет ли лиц, номеров машин и схемы слепых зон.

## Кейсы по старым сделкам
Сделку не нужно переносить в «Проверено» (сработают уведомления, а у закрытой сделки сменится дата закрытия). Напишите в группу MAX:
- `кейс 6912345` — номер сделки: последние цифры в адресе сделки (`…/leads/detail/6912345`) или «№» в карточке;
- можно ссылкой: `кейс https://01fevralev.amocrm.ru/leads/detail/6912345`;
- несколько сразу: `кейсы 6912345, 6898765` (не больше 10 за раз).
Бот ответит «Собираю…», черновики придут как обычно. У сделки должна быть заполнена «Папка Контент» с фото.

## Исправить опубликованный кейс
Страница на сайте сама за сделкой не следит. Если в сделке была ошибка (например, даты монтажа):
1. Исправьте поле в amoCRM.
2. Напишите в группу `кейс N` (номер этой сделки) — придёт черновик «Обновление кейса». История, выбранные фото, обложка и вручную исправленный адрес сохраняются.
3. «Опубликовать» — страница обновится по тому же адресу.
Если монтаж длиннее 5 дней, черновик сам предупредит: «⚠️ проверьте даты».

## Важно для GitHub Desktop
Функция сама кладёт кейсы в репозиторий на GitHub. Перед своими правками сайта нажимайте **Fetch origin**, а если появится **Pull origin** — нажмите и его. Иначе GitHub Desktop не даст запушить.

## Настройка (один раз, ~30 минут)

Уже сделано: скрипт «Мой Дозор фото» (`backend/drive-script/Code.gs`), бакет `moidozor-cases`, сервисный аккаунт `moidozor-case`, ключ GitHub.

### 1. Роль для таймера
Identity and Access Management → Сервисные аккаунты → `moidozor-case` → **Назначить роли** → добавить `functions.functionInvoker` → Сохранить. Итого у аккаунта три роли: `ai.languageModels.user`, `storage.editor`, `functions.functionInvoker`.

### 2. Функция
1. Cloud Functions → **Создать функцию** → имя `moidozor-case` → Создать.
2. Среда **Node.js 22**, «Редактор кода». Создать три файла (кнопка «Создать файл») и в каждый вставить содержимое одноимённого файла из этой папки:
   `index.js`, `render.js`, `package.json`.
   Удобно копировать с GitHub: открыть файл → кнопка **Copy raw file** справа над кодом.
   В `package.json` должны быть три зависимости: `sharp` и две его детали под сервер Яндекса (`@img/sharp-linux-x64`, `@img/sharp-libvips-linux-x64`) — без них функция не запустится с ошибкой «Could not load the "sharp" module».
3. Точка входа: `index.handler`. Таймаут: **120** секунд. Память: **512 МБ**.
4. Сервисный аккаунт: **moidozor-case**.
5. Переменные окружения:

| Переменная | Что вписать |
|---|---|
| `HOOK_SECRET` | придумайте длинный пароль из латинских букв и цифр (20+) |
| `AMO_DOMAIN` | как в функции заявок `moidozor-lead` |
| `AMO_TOKEN` | как в функции заявок |
| `MAX_TOKEN` | как в функции заявок (скопировать без пробелов) |
| `MAX_CHAT_ID` | как в функции заявок |
| `DRIVE_SCRIPT_URL` | адрес скрипта «Мой Дозор фото», заканчивается на `/exec` |
| `DRIVE_SECRET` | пароль скрипта |
| `GITHUB_TOKEN` | ключ GitHub `github_pat_…` |
| `FOLDER_ID` | `b1gbfean1ejk136uqb5m` |

6. **Создать версию.** Первая сборка идёт дольше обычного (ставится `sharp` для сжатия фото).
7. Вкладка **Обзор** → включить **Публичная функция**.

### 2а. Бот — администратор группы MAX
Группа с черновиками → название группы → **Участники** → бот → **Назначить администратором**. Иначе бот видит нажатия кнопок, но не видит ваши ответы на черновик (`история: …`, `оставить …`).

### 3. Проверка настроек
Открыть в браузере (ID — со вкладки «Обзор» функции, пароль — `HOOK_SECRET`):

```
https://functions.yandexcloud.net/ID_ФУНКЦИИ?setup=1&s=ПАРОЛЬ
```

Должны быть все ✅. Заодно эта страница подписывает бота MAX на нажатия кнопок и показывает **адрес для amoCRM**.
Если адреса на странице начинаются не с вашего ID функции — добавьте переменную `SELF_URL` = `https://functions.yandexcloud.net/ID_ФУНКЦИИ`.

### 4. Таймер
В функции → вкладка **Триггеры** → **Создать триггер**:
- Тип: **Таймер**, cron-выражение: `* * * * ? *` (каждую минуту)
- Функция: `moidozor-case`, тег версии `$latest`
- Сервисный аккаунт: `moidozor-case`

Раз в минуту функция заглядывает в очередь — это бесплатно в пределах лимитов Яндекс Облака.

### 5. amoCRM
Сделки → **Настроить** (цифровая воронка «Основная») → колонка **«Проверено»** → **+ Добавить триггер** → **Webhook** → вставить адрес из шага 3 → условие «при переходе или создании в этапе» → **Сохранить**.

### 6. Проверка целиком
Перевести сделку, у которой в «Папке Контент» есть фото, на «Проверено» → через 1–2 минуты в группе MAX черновик и фото. Попробовать `убрать 2`, `обложка 3`, «короче» → **Опубликовать** → через 1–2 минуты кейс на сайте, бот пришлёт ссылку.

## Если что-то не работает
- **Черновик не пришёл** — функция → «Логи»: там текст ошибки. Бот в MAX тоже пишет «⚠️ Не получилось…».
- **Ответы на черновик бот не замечает** — сделайте бота администратором группы MAX (иначе он может не видеть сообщения) и откройте страницу проверки из шага 3 ещё раз.
- **Кнопки не нажимаются** — откройте страницу проверки из шага 3: строка «MAX: подписка бота» должна быть ✅.
