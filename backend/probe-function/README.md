# Проверка связи для автокейсов

Функция только проверяет, открываются ли из Яндекс Облака Google Диск, GitHub, YandexGPT, Object Storage и события бота MAX. Ничего не создаёт и не меняет. После проверки её можно удалить.

## Как запустить (5 минут)
1. Яндекс Облако → Cloud Functions → «Создать функцию», имя `moidozor-probe`.
2. Среда **Node.js 18** (или новее), способ — «Редактор кода». Вставить содержимое `index.js` из этой папки целиком.
3. Точка входа: `index.handler`. Таймаут: 30 секунд.
4. Переменные окружения (необязательно, но полезно):
   - `MAX_TOKEN` — тот же токен бота, что в функции заявок;
   - `DRIVE_FOLDER` — ссылка из поля «Папка Контент» любой сделки.
5. «Создать версию», затем вкладка «Тестирование» → «Запустить тест».
6. Прислать мне блок `summary` из результата: строки с ✅ и ❌.

`404` или `401` рядом с ✅ — это нормально: сервис ответил, значит, он доступен. Плохо только ❌ (тайм-аут или ошибка соединения).
