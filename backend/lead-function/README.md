# Приём заявок: сайт → amoCRM + уведомление в MAX

Функция `index.js` для Яндекс Облака (Cloud Functions), адрес `https://functions.yandexcloud.net/d4eirdv1tglmcebcq8qj`. Сайт отправляет ей заявку, она создаёт сделку в amoCRM (этап «НОВЫЙ ЛИД») и присылает уведомление в группу MAX. Если amoCRM недоступна, уведомление всё равно приходит с пометкой «внесите вручную».

**Telegram:** из Яндекс Облака `api.telegram.org` недоступен (26.09.2026 два раза подряд — таймаут соединения). Бот `@moidozor_leads_bot` и группа (`-5236379545`) созданы, но работать они смогут только через посредника за рубежом (переменная `TG_API`). Без посредника `TG_TOKEN` не задавать.

## Настройка в Яндекс Облаке

1. console.yandex.cloud → **Cloud Functions** → **Создать функцию**, имя `moidozor-lead`.
2. Редактор: среда **Node.js 22** (или 18), способ — «Редактор кода», файл `index.js` — вставить содержимое `index.js` отсюда. Точка входа: `index.handler`. Таймаут 15 с, память 128 МБ.
3. **Переменные окружения** (секреты вводит владелец, в код и в чат не вставлять):

| Переменная | Значение |
|---|---|
| `MAX_TOKEN` | токен бота MAX (business.max.ru → Чат-боты → бот → Интеграция) |
| `MAX_CHAT_ID` | номер группы MAX. Как узнать: задать только `MAX_TOKEN`, добавить бота в группу, написать там сообщение, отправить тестовую заявку — номер появится в **Логах** («Бот состоит в группах: …») |
| `AMO_DOMAIN` | `01fevralev.amocrm.ru` |
| `AMO_TOKEN` | долгосрочный токен интеграции amoCRM |
| `AMO_STATUS` | `НОВЫЙ ЛИД` — этап основной воронки, куда ставить заявки |
| `AMO_PIPELINE` | необязательно: название другой воронки (без него — основная) |
| `AMO_JOBS_PIPELINE` | `Кандидаты` — воронка для откликов на вакансии (без неё отклики приходят только в MAX) |
| `ALLOWED_ORIGINS` | `https://xn--d1agelkcbq.xn--p1ai,https://01fevralev-alt.github.io` |

4. **Создать версию**, затем в обзоре функции включить **«Публичная функция»** и скопировать ссылку вида `https://functions.yandexcloud.net/d4e…`.
5. Эту ссылку вписать в `index.html` → `SITE.leadEndpoint` и опубликовать сайт.

## Виды заявок

- **Клиент** (`index.html`) — сделка «Заявка с сайта» в «НОВЫЙ ЛИД», тег `сайт`; если нажали «Хочу так же» — в примечании, какой кейс понравился.
- **Рекомендация** (`partner.html`) — сделка «Заявка на партнерство от клиента» на знакомого, теги `сайт`, `партнёр`; в примечании — кто рекомендовал и условия (10 %, до 50 000 ₽, после аванса; регистратор ATIX AT-NVR-1109 (v2) знакомому).
- **Отклик** (`jobs.html`) — сделка «Отклик на вакансию «Монтажник»» в воронке `AMO_JOBS_PIPELINE`, тег `вакансия`.

## Если что-то не работает

- Логи: функция → **Логи**. Ошибки amoCRM и Telegram пишутся туда.
- Заявки встают не на тот этап — в логах будет «Этап … не найден. Есть: …»: скопировать точное название этапа в `AMO_STATUS`.
- `MAX 401` в логах — неверный `MAX_TOKEN`.
- Сайт ждёт ответа функции не дольше 15 с; сама функция ждёт amoCRM до 8 с, мессенджер до 5 с.
- Токен amoCRM долгосрочный, но у него есть срок, выбранный при создании: перед истечением выпустить новый и заменить `AMO_TOKEN`.
