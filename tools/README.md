# Служебные скрипты сайта «Мой Дозор»

- `build_map.py` — собирает карту объектов (SVG-пути) из открытых данных Natural Earth.
  Нужные файлы данных скачать рядом со скриптом:
  - https://cdn.jsdelivr.net/npm/world-atlas@2/countries-50m.json
  - https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson
  - https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_rivers_lake_centerlines.geojson
  Проекция карты на сайте: Меркатор, окно 20–90° в. д., верх 62,5° с. ш., viewBox 1200×600
  (класс `View(20, 90, 62.5, 1200, 600)`); по ней же ставить точки городов.
  Лупу из скрипта (секция magnifier) на сайте больше не используем.
- `build_objects.py` — собирает из amoCRM плашки карты: по наведению на город — список
  «тип — адрес — камеры». Точек отдельных объектов на карте нет (в масштабе России их не видно).
  Запуск из папки сайта: `python3 tools/build_objects.py` (`--dry-run` — только отчёт). Берёт все CSV из `data/` (экспорт сделок amoCRM) и переписывает
  в `index.html` блок между `// CRM-OBJECTS:BEGIN` и `// CRM-OBJECTS:END`.
  - На карту идут сделки воронки «База клиентов» с адресом и типом объекта, из других воронок —
    только с прошедшей «Датой окончания монтажа»; сделки с «Причиной отказа» не идут.
  - Имена и телефоны не выводятся; в плашке улица и номер дома (корпус, строение, литера — да;
    офис и квартира — нет), у частных домов, дач и квартир — улица без номера дома
    (посёлки Самары — «пос. Зубчаниновка», просеки — «8-я просека», СНТ — «СНТ «Огонек»»).
  - Точные камеры: `tools/objects_extra.json` → `cams` (`"ID сделки": число`), либо заполнить
    «Камер (шт)» в amoCRM и перевыгрузить. Где пусто — оценка по типу объекта (в отчёте «≈»).
  - Тестовые адреса Москвы, Петербурга и Уфы — `objects_extra.json` → `demo`, в плашке пометка «Пример».
  - Новый посёлок: добавить шаблон в `PLACES` и координаты в `TOWNS` (Википедия); про незнакомые
    адреса скрипт предупреждает в отчёте.
- `transcode.swift` — сжимает рилсы в MP4 540×960 не больше заданного размера и снимает обложку.
  Сборка: `swiftc -swift-version 5 -O transcode.swift -o transcode`
  Запуск: `./transcode <исходник> <выход.mp4> <обложка.jpg> 14000000`
